# ALAKÓL — туристическая платформа озера Алаколь

Полноценный статический сайт-платформа о разноцветном озере **Алаколь** на стыке областей **Абай** и **Жетісу**. Готов к публикации на **GitHub Pages** без сборки и зависимостей.

## Что внутри

Многостраничная структура с понятной логикой: каждая страница отвечает на один вопрос путешественника.

| Страница | Файл | О чём |
|---|---|---|
| Главная | `index.html` | Живая сцена озера (оттенок воды по сезону выбранной даты + освещение по текущему времени суток), ключевые цифры, интерактивная карта, навигация по разделам |
| Почему Алаколь | `why.html` | 6 интерактивных карточек-аргументов |
| Как добраться | `route.html` | Выбор точки старта → способы доезда + карта |
| Где остановиться | `stay.html` | 3 зоны берега, фильтры, онлайн-бронирование |
| Ландшафт | `explore.html` | Исторический / природный / культурный / научный взгляд |

### Ключевые особенности
- **Два языка — казахский и русский.** Переключатель в шапке, выбор запоминается (`localStorage`) и действует на всех страницах.
- **Настоящая карта Казахстана.** Силуэт построен из реальных границ (Natural Earth), города, озеро и погранпереходы расставлены по действительным координатам. Всё кликабельно и анимировано: маршруты, бегущий импульс, подсветка регионов, всплывающие подсказки.
- **Живая сцена озера** на главной — вода и освещение меняются динамически.
- Адаптивная вёрстка, mobile-first, поддержка `prefers-reduced-motion`.

## Структура проекта

```
alakol-platform/
├── index.html · why.html · route.html · stay.html · explore.html
├── assets/
│   ├── css/styles.css        # общие стили
│   └── js/
│       ├── i18n.js           # словари KZ/RU + переключение языка
│       ├── components.js      # шапка, подвал, меню, активный пункт
│       ├── main.js            # анимации появления, счётчики, тосты
│       ├── map.js             # интерактивная карта Казахстана
│       ├── scene.js           # живая сцена озера (главная)
│       └── stay.js            # зоны, фильтры, бронирование
├── .nojekyll                  # чтобы GitHub Pages не обрабатывал сайт через Jekyll
└── README.md
```

Технологий сборки нет — чистые HTML/CSS/JS. Достаточно открыть `index.html` в браузере.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub (например, `alakol`).
2. Загрузите содержимое папки `alakol-platform` в корень репозитория:

   ```bash
   cd alakol-platform
   git init
   git add .
   git commit -m "ALAKÓL tourism platform"
   git branch -M main
   git remote add origin https://github.com/USERNAME/alakol.git
   git push -u origin main
   ```

3. В репозитории: **Settings → Pages**.
4. В блоке **Build and deployment** → **Source** выберите **Deploy from a branch**, ветку **main**, папку **/(root)**, нажмите **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу:

   ```
   https://USERNAME.github.io/alakol/
   ```

> Файл `.nojekyll` уже добавлен — он нужен, чтобы GitHub Pages отдавал сайт как есть.

## Как редактировать контент

- **Тексты и переводы** — `assets/js/i18n.js` (объекты `ru` и `kz`). Элементы в разметке помечены атрибутом `data-i18n="ключ"`.
- **Точки и маршруты на карте** — `assets/js/map.js` (массив `PINS`, словари `NAMES`, `POINTS`, `JOURNEY`).
- **Отели и цены** — `assets/js/stay.js` (объект `HOTELS`).
- **Цвета и шрифты** — переменные в начале `assets/css/styles.css`.
